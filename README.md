# MenuBoxGh 🍽️

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

**MenuBoxGh** is a SaaS platform for food vendors in Ghana to create digital menus, generate QR codes, and accept orders via WhatsApp.

## ✨ Features

- 📱 **Digital Menu** - Create and manage food items with images
- 📊 **QR Code Generation** - Unique QR codes for each vendor
- 💬 **WhatsApp Integration** - Orders sent directly via WhatsApp
- 💰 **Subscription Management** - 180 GHS/month with Paystack
- 📈 **Analytics Dashboard** - Track orders and popularity

## 🛠️ Tech Stack

- **Frontend**: Next.js 14 + Tailwind CSS
- **Backend**: Node.js + Express
- **Database**: PostgreSQL + Prisma
- **Payments**: Paystack
- **Storage**: Cloudinary
- **Deployment**: Vercel (FE) + Railway (BE)
